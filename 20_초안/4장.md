# 4. 비용과 담당

시범 운영 비용은 [확인 필요]입니다. 참고로 작년 주간보고 양식 통일 시범 운영은 기존 사내 문서 도구를 써서 별도 예산 없이 진행했습니다(작년_기획안_요약.md). 이번에도 같은 방식으로 진행할 수 있는지는 회의록 보관 위치를 정한 뒤 확인하겠습니다(5장).

| 항목 | 내용 |
|---|---|
| 예산 | [확인 필요] |
| 사용 도구 | [확인 필요] (회의록 보관 위치가 아직 정해지지 않음 — 회의메모_1006.md) |
| 투입 시간 | 작성 안내 준비·진행 시간 [확인 필요] |

**담당**

| 역할 | 담당 |
|---|---|
| 시범 운영 총괄 | [확인 필요] |
| 양식 배포·작성 안내 | [확인 필요] |
| 월별 지표 기록 | [확인 필요] |
| 결과 보고서 작성 | [확인 필요] |

회의록 작성자는 회의마다 바뀝니다(회의메모_0922.md). 따라서 작성자와 별도로 지표를 기록할 담당자를 정해 두어야 합니다.
