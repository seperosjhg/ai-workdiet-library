# 기획안 목차 3안: 2027년 팀 회의록 양식 표준화 시범 운영

> 퍼블리 실습용 가상 데이터 기반. 근거는 `20_초안/근거표.md`를 따른다.
> 표기: ★ = 결재권자가 가장 먼저 물을 질문의 답이 들어갈 위치 / [확인 필요] = 10_자료에 근거가 없어 비워 둘 칸

## 세 안 공통

- **첫 문단 (결론·요청)**: 2027년 1분기 3개월 동안 운영지원팀 1개 팀에서 회의록 3칸 양식(결정 사항 / 후속 조치(담당·기한) / 참고 사항)을 시범 운영하고, 결과를 보고한 뒤 확대 여부를 결정하도록 승인을 요청한다.
  - 근거: 1분기 시범 운영 제안(회의메모_1006.md), "한 팀, 3개월 시범 → 결과 보고 → 확대 결정"을 선호하는 결재권자 성향(결재권자_메모.md)
- 분량은 A4 2장 이내, 장 제목은 5개 이내로 한다. 첫 문단은 장 수에 넣지 않는다.
- 결재권자가 늘 묻는 질문 네 가지(왜 지금 / 얼마나 / 안 하면 / 누가)는 세 안 모두 본문 어딘가에서 답한다. 안마다 **어느 질문을 맨 앞에 두느냐**가 다르다.

## 1안. 성과 중심

**결재권자가 가장 먼저 물을 질문**: "숫자로 효과가 보이나?"
(결재권자는 숫자 근거를 먼저 보고, 근거 없는 기대 효과 문장은 지운다 — 결재권자_메모.md)

| 장 | 제목 | 들어갈 내용 (출처) |
|---|---|---|
| 1 | 현재 회의록의 문제 | 7~9월 결정 사항 칸 없는 회의록 월 3~5건, 다시 확인한 후속 조치 월 5~7건, 작성 시간 평균 31~36분 (회의록_실적표.csv) |
| 2 ★ | 사전 시험과 선례로 본 효과 | 10월 3칸 양식 자율 사용 4건: 작성 시간 평균 18분, 결정 사항 칸 없는 회의록 0건, 다시 확인한 후속 조치 1건 (회의록_실적표.csv) / 작년 주간보고 시범 운영: 취합 시간 주당 약 90분 → 약 40분, 8명 중 7명 계속 사용 의사 (작년_기획안_요약.md) |
| 3 | 시범 운영 계획과 측정 지표 | 대상·기간, 측정 지표 3개(작성 시간, 결정 사항 칸 누락, 후속 조치 재확인) / 성과 목표치 [확인 필요] |
| 4 | 비용과 담당 | 비용 [확인 필요] (작년 선례는 별도 예산 없음 — 작년_기획안_요약.md) / 담당자 [확인 필요] |
| 5 | 결정 요청 사항 | 시범 운영 승인, 회의록 보관 위치 결정 (회의메모_1006.md), 다른 팀 확대는 결과 보고 후 결정 |

**네 가지 질문의 답 위치**: 왜 지금 → 1장 / 얼마나 → 4장 / 안 하면 → 1장 / 누가 → 4장

- 강점: 결재권자의 "숫자 먼저" 성향과 맞는다. 작년에 본부장이 좋게 평가한 방식("작게 해 보고 숫자로 보여 준 게 좋았다")을 그대로 따른다.
- 약점: 핵심 근거인 10월 수치가 회의 4건뿐이다. 2장에 "표본 4건, 정식 검증은 시범 운영에서"라고 밝히지 않으면 과대 해석으로 읽힐 수 있다.

## 2안. 리스크 중심

**결재권자가 가장 먼저 물을 질문**: "안 하면 어떻게 되나?"

| 장 | 제목 | 들어갈 내용 (출처) |
|---|---|---|
| 1 ★ | 지금 생기고 있는 문제 | 장애 대응 연락 순서를 두 사람이 서로 다르게 기억한 사례 (회의메모_0915.md) / 후속 조치의 담당·기한이 남지 않아 다음 회의에서 다시 확인, 월 5~7건 (회의메모_0922.md, 회의록_실적표.csv) |
| 2 | 그대로 두면 생길 일 | 7~9월 현황이 이어진다는 서술까지만 가능. 정량 전망은 [확인 필요] |
| 3 | 대응: 3칸 양식 시범 운영 | 양식 구성 (회의메모_0922.md), 10월 자율 사용 결과 (회의록_실적표.csv) |
| 4 | 시범 운영의 위험과 대비 | 작성 부담 반대 의견 1명 (회의메모_0922.md) / 작년 첫 달 혼선은 작성 안내가 없었기 때문 → 작성 안내를 후속 조치로 넣음 (작년_기획안_요약.md), 안내 계획 [확인 필요] |
| 5 | 결정 요청 사항 | 시범 운영 승인, 비용·담당 [확인 필요], 회의록 보관 위치 결정 |

**네 가지 질문의 답 위치**: 왜 지금 → 1장 / 얼마나 → 5장 / 안 하면 → 1·2장 / 누가 → 5장

- 강점: 장애 대응 연락 순서처럼 운영에 직접 닿는 사례가 있어 문제의 무게가 잘 전달된다. 반대 의견과 작년 혼선을 먼저 다뤄 반론을 미리 막는다.
- 약점: 2장은 정량 근거가 없다. 근거 없는 기대 효과 문장을 지우는 결재권자 성향상 2장은 짧게 쓰거나 1장에 합쳐야 한다.

## 3안. 예산·일정 중심

**결재권자가 가장 먼저 물을 질문**: "돈은 얼마나 들고, 왜 지금인가?"
(예산이 드는 안은 왜 지금이어야 하는지를 꼭 묻는다 — 결재권자_메모.md)

| 장 | 제목 | 들어갈 내용 (출처) |
|---|---|---|
| 1 ★ | 비용 | 시범 운영 비용 [확인 필요] / 참고: 작년 주간보고 시범 운영은 별도 예산 없이 기존 사내 문서 도구 사용 (작년_기획안_요약.md) |
| 2 ★ | 왜 지금인가 | 9월 팀 회의에서 문제 제기 (회의메모_0915.md, 회의메모_0922.md) → 10월 2주 자율 시험 완료 (회의메모_1006.md) → 2027년 1분기에 바로 시작할 수 있는 상태 |
| 3 | 일정 | 2027년 1분기 3개월 시범 → 결과 보고 → 확대 결정 (회의메모_1006.md, 결재권자_메모.md) / 정확한 시작·종료일 [확인 필요] |
| 4 | 추진 체계와 측정 지표 | 담당자·역할 [확인 필요] / 측정 지표는 회의록_실적표.csv의 3개 항목 |
| 5 | 결정 요청 사항 | 시범 운영 승인, 회의록 보관 위치 결정, 다른 팀 확대는 결과 보고 후 결정 |

**네 가지 질문의 답 위치**: 왜 지금 → 2장 / 얼마나 → 1장 / 안 하면 → 2장 (보조) / 누가 → 4장

- 강점: 결재권자가 예산 안건에 던지는 첫 질문에 바로 답한다. "작게, 3개월" 일정이 선호 순서와 같다.
- 약점: 1장과 4장의 핵심 칸(비용, 담당자)이 지금은 비어 있다. 이 칸을 채우지 못하면 첫 장부터 [확인 필요]가 보인다.
