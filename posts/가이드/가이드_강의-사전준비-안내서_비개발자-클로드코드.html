[사전 준비 안내서] 클로드코드 병아리반

오시기 전에 해두실 4가지 — 설치는 각자 미리, 강의는 실습만.

대상: 클로드코드를 처음 쓰시는 사업관리·어드민 담당자 · 소요 40~60분 · Windows 10/11 기준

0. 준비물 체크리스트 — 이것만 되면 준비 끝

#항목확인 방법완료
1Claude 유료 결제(Pro 이상)claude.ai 로그인 → 요금제가 Pro로 표시☐
2Node.js 설치명령어 창에 node -v → v18 이상 출력☐
3Claude Code 설치·로그인명령어 창에 claude → 실행됨☐
4Git 설치명령어 창에 git --version → 버전 출력☐
5Playwright 설치5번 절차 → 브라우저 창이 뜸☐
6작업 폴더 1개 생성예: 바탕화면\클로드실습☐
"명령어 창"이 뭔가요? 시작 버튼 검색창에 powershell 이라고 치면 나오는 검은(또는 파란) 창입니다.
cmd(명령 프롬프트)를 여셔도 아무 상관 없습니다. 아래 명령어는 둘 다에서 똑같이 동작하니 편한 쪽으로 여시고, 명령어를 붙여넣은 뒤 Enter를 치시면 됩니다.

1. Claude 유료 결제 (필수)

  • 무료 플랜으로는 클로드코드를 쓸 수 없습니다. 무료는 웹 채팅만 됩니다.
  • claude.ai 로그인 → 설정 → 요금제 → Pro 결제.
  • 회사 카드로 결제하실 분은 사전에 결재 라인을 잡아두세요. 당일 결제 시도 → 승인 대기로 실습을 못 하실 수 있습니다.
  • 처음엔 Pro면 충분합니다. 실습(자동화 도구 만들기)은 Pro 한도 안에서 됩니다. 상위 플랜은 필요해지면 그때 올리셔도 됩니다.

2. Node.js 설치

  1. https://nodejs.org 접속 → LTS 버전 다운로드(Windows Installer)
  2. 다운로드된 파일 실행 → 계속 "다음"(기본값 그대로)
  3. 확인: 명령어 창을 새로 열고
node -v

→ v20.x.x 처럼 숫자가 나오면 성공입니다. (v18 이상이면 OK)

3. Claude Code 설치 및 첫 로그인

명령어 창에서 아래를 차례로 실행합니다.

npm install -g @anthropic-ai/claude-code
claude
  • 브라우저가 열리며 로그인을 요청합니다 → 1번에서 결제한 계정으로 로그인.
  • 실행되면 성공입니다. 종료는 /exit 또는 창 닫기.
첫 세팅(선택, 5분) — 나를 어떻게 부를지, 내 업무가 무엇인지, 답변 스타일(결론 먼저 / 숫자 포함 / 아첨 금지)을 적어두는 개인화 설정입니다. 잘 모르겠으면 클로드에게 그대로 물어보세요.
"나 하나도 몰라. 클로드 지침(개인화 설정)을 어디서 어떻게 넣는지 유치원생한테 알려주듯 단계별로 알려줘."

4. Git 설치

  1. https://git-scm.com/download/win 접속 → 다운로드 → 실행
  2. 옵션이 많이 나오는데 전부 기본값으로 "Next" 하시면 됩니다
  3. 확인: 명령어 창을 새로 열고
git --version

→ git version 2.x.x 가 나오면 성공.

5. Playwright 설치 (실습 핵심 도구)

브라우저를 대신 클릭·입력해주는 자동화 도구입니다. 이번 실습의 핵심이라 반드시 준비해주세요.

① 6번에서 만든 작업 폴더로 이동 (경로는 본인 것으로)

cd C:\Users\사용자명\Desktop\클로드실습

② 설치

npm init -y
npm install -D @playwright/test
npx playwright install chromium

③ 동작 확인 — 실행하면 브라우저 창이 하나 열립니다.

npx playwright codegen https://www.naver.com

창이 뜨고, 마우스로 클릭할 때마다 옆 창에 코드가 자동으로 쌓이면 준비 완료입니다. 이게 강의 때 쓸 기능입니다. 창은 그냥 닫으셔도 됩니다.

6. 작업 폴더 만들기

  • 바탕화면에 클로드실습 같은 폴더를 하나 만들어 주세요.
  • 강의 때 만드는 결과물은 전부 이 폴더에 쌓입니다. 미리 정해두지 않으면 매번 "어디에 저장할까요?"에서 멈춥니다.

7. 강의 당일 가져오실 것

  • 위 6가지가 완료된 본인 노트북(충전기 포함)
  • 자동화하고 싶은 내 업무 1개를 생각해 오세요. 반복 클릭이 많은 것일수록 좋습니다.
    예: 매달 같은 시스템에 같은 형식으로 등록하는 일 / 파일 여러 개를 PDF로 변환 / 표 옮겨 적기
    그 업무의 화면 URL과 클릭 순서를 대략 적어오시면 당일에 바로 만들어볼 수 있습니다.
⚠️ 보안 주의 — 아이디·비밀번호는 채팅창에 적지 마세요. 당일에 다루는 방법을 따로 안내합니다. 사내 시스템 자동화는 각자 권한 범위 안에서만 진행합니다.
