🧑‍🏫 VS Code로 클로드 쓰기 — 왕초보 완전 입문

대상: VS Code 설치만 해둔 사전지식 0 · 환경: Windows 11 · Claude Pro 요금제 · 2026-07-08
공식 문서(code.claude.com) 확인 기준. 화면 문구는 버전에 따라 조금 다를 수 있어요.

0. 먼저, 아주 쉽게 — VS Code가 뭔가요?

VS Code는 "글·파일을 쓰고 정리하는 공짜 프로그램"입니다. 한글 워드가 문서 편집기라면, VS Code는 코드·파일 편집기예요.

여기에 클로드를 붙이면 이렇게 좋아집니다:

  1. 파일을 고치기 전에 "이렇게 바꿀게요"를 양쪽 비교(before/after)로 미리 보여줌 → 수락/거절
  2. 열어 둔 파일이나 드래그로 선택한 부분을 클로드가 자동으로 봄
  3. 계획(Plan)을 먼저 보여주고 시작하게 할 수 있음 ← 조차장님이 좋아하시는 "만들기 전에 확인"과 딱 맞음

한마디로 "클로드가 하는 일을 눈으로 보면서, 확인받고 진행"하게 됩니다.

1. 준비 확인 (30초)

• VS Code 버전 1.98.0 이상 — 확인: 상단 Help(도움말) → About(정보). 낮으면 최신으로 재설치.
• Claude Pro 계정이면 충분. API 키 필요 없음. 로그인만 하면 끝.

STEP 1 클로드 확장 설치

"확장"은 VS Code에 기능을 더하는 부품이에요.

  1. VS Code를 엽니다.
  2. Ctrl + Shift + X 를 누릅니다 → 왼쪽에 "확장" 창이 열려요.
  3. 검색칸에 Claude Code 입력.
  4. 맨 위 Claude Code(만든 곳: Anthropic) 의 파란 Install(설치) 클릭.
  5. 잠시 기다리면 완료. (반응 없으면 VS Code 껐다 켜기)

STEP 2 로그인

  1. 클로드 창을 처음 열 때 로그인 화면이 뜹니다. (안 뜨면 STEP 4 먼저)
  2. Sign in(로그인) 클릭.
  3. 브라우저가 열리면 Claude 계정으로 로그인 → 승인(Authorize).
  4. "완료" 뜨면 VS Code로 돌아오기. 끝!
✅ Pro 계정으로 로그인하면 추가 비용 없이 그대로 씁니다.

STEP 3 내 작업 폴더 열기 (중요!)

클로드는 "어느 폴더에서 일할지"를 알아야 합니다. 작업이 다 있는 claude-sit를 열어줍니다.

  1. 상단 메뉴 File(파일) → Open Folder…(폴더 열기)
  2. 경로로 이동: C:\Users\82106\Desktop\클로드코드\claude-sit
  3. 폴더를 클릭 선택 → "폴더 선택" 버튼
  4. "작성자를 신뢰합니까?" 창이 뜨면 "예, 신뢰합니다" (내 폴더라 안전)
  5. 왼쪽에 업무대시보드·블로그 등 내 파일 목록이 보이면 성공.
💡 "폴더를 연다" = 클로드에게 "이 방 안에서 일해"라고 방을 정해주는 것.

STEP 4 클로드 대화창 열기

클로드 아이콘은 ✱ 모양(Spark, 반짝이)입니다. 셋 중 아무거나:

  1. (가장 쉬움) 아무 파일이나 열면 편집기 오른쪽 위 구석에 ✱ 아이콘 생김 → 클릭
  2. 왼쪽 세로 막대의 ✱ 아이콘 → 클릭 (파일 안 열어도 늘 보임)
  3. 오른쪽 아래 구석 ✱ Claude Code 글자 → 클릭
헷갈리면: Ctrl+Shift+P → Claude Code 입력 → "Open in New Tab" 선택.

STEP 5 첫 대화 연습

대화창 아래 입력칸에 한국어로 그냥 말 걸면 됩니다. 연습:

@업무대시보드/00-로드맵.md 이 파일 지금 상태를 세 줄로 요약해줘

• @를 치면 파일 목록이 뜸 — 이름 일부만 쳐도 찾아줌(예: @로드맵).
• 또는 파일을 열고 마우스로 특정 부분 드래그(선택) 후 "이 부분 고쳐줘" → 선택 부분을 클로드가 자동으로 봄.

STEP 6 클로드가 고친 걸 검토하기 (핵심)

클로드가 파일을 고치려 하면 바로 고치지 않고 먼저 비교 화면을 보여줍니다:

- 원래 내용 (빨강 = 지움)
+ 바꿀 내용 (초록 = 추가)

그 아래 "이대로 할까요?" → 수락(Accept) / 거절(Reject) / "이렇게 말고 저렇게" 다시 말하기.

💡 이게 VS Code의 가장 큰 장점 — 결과만 받는 게 아니라, 바뀌기 전에 눈으로 보고 결정.

★ 조차장님께 특히 추천 = Plan 모드. 어제 "개발 전에 계획·요구부터 확정하고 컨펌받자"라고 하셨죠? Plan 모드가 바로 그겁니다 — 클로드가 뭘 할지 계획을 문서로 펼쳐 보여주고, 조차장님이 코멘트·승인한 뒤에야 실제 작업을 시작합니다. 일하는 방식과 완벽히 맞습니다.
